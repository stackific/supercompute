<AboutSection title="About Supercompute">

Self-host a purpose-built cloud for AI-first workloads on commodity hardware—in your laptop VM, on a NAS, or on public nodes. You provide a static IP for public endpoints and a Postgres database with owner role hosted outside of the Supercompute cloud. High availability is achievable with as few as two nodes.

Created by [Stackific Inc.](https://stackific.com)
